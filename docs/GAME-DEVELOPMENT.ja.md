# ゲーム制作テンプレート

ホームの「ゲーム制作」、または `/ja/new/game-development/` から開始します。日本語・英語・スペイン語に対応し、10カテゴリ・40問で今回の制作の前提を整理します。

| カテゴリ | 整理する内容 |
| --- | --- |
| 企画・プレイ体験 | 制作目標、届けたい体験、制作フェーズ、コンセプト |
| プレイヤー・遊ぶ環境 | 対象者、機種、人数・参加方式、プレイ時間 |
| 遊びの循環・ルール | 基本の遊び、成功・失敗、成長、難易度 |
| 制作範囲・コンテンツ | 制作量、必要機能、対象外、引き継ぐ資産 |
| 美術・音・物語 | 見た目、物語、音、素材の制作・承認 |
| 技術・保存 | エンジン、入力、セーブ、ネットワーク |
| 操作性・アクセシビリティ | 遊び方の案内、操作支援、性能、中断・復帰 |
| 守る境界・権利 | 表現・交流の限界、収益化、データ、利用条件 |
| 制作体制・公開 | 人員・予算・時間、配布、納品物、保守 |
| プレイテスト・完成判定 | 楽しさの検証、必須試験、決定者、未決定の扱い |

## 入力例

- 制作目標：試作で遊びの核を検証。
- 届けたい体験：探索と発見。
- 基本の流れ：部屋を探索し、道具を見つけ、その道具で次の部屋への道を開く。
- 制作量：部屋3つ、道具2つ、10分以内で最後まで遊べる試作。
- 対象外：オンライン対戦、課金、複数セーブスロット。
- 検証：初めて遊ぶ3人が説明なしに最初の道具を使えるか観察し、詰まった箇所を記録する。

これは説明用の例です。新規プロジェクトの回答として自動入力されません。

## 回答と決定

選択式と自由記述を組み合わせます。「その他」は補足必須です。「未決定」「提案を求める」は決定済みの設計として扱われません。複数選択の「必要なし」「未決定」「提案を求める」は他の選択肢と併用できません。自由記述も、未解決のままにできます。

回答（Contribution）を記録した後、採用する回答・決定者・状態をResolutionで明示します。決定権者は各カテゴリを確定でき、技術・保存カテゴリでは実装権限を持つ回答元も決定者になれます。推測と本人の報告は分けてください。

オンラインの参加方式とオフライン完結を同時に選ぶと、レビューに警告が表示されます。警告は判断を促すもので、回答を自動修正しません。

Baseの明示確定、Override、Unified、AI Context Markdown、JSONインポートは既存のWeb用と共通です。インポート時にはJSON内のテンプレートIDで質問セットを選びます。画面言語を変えてもID・選択値・元のメモは保持されます。

## 変更の境界

この追加はゲーム制作の質問テンプレートと、ホーム下部の作者・関連ツールへのリンクです。ゲームそのものを生成する機能や、Preference Compassの個人シートを読み込む機能は含みません。個人シートの回答は質問の既定値や公開データに組み込んでいません。

質問の編集元は `scripts/generate-game-questions.mjs`、生成先は `templates/game-development/` です。`npm run check` で生成・テスト・全テンプレートの静的検証を行います。
