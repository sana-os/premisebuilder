# Privacy

Premise Builder is a static, browser-local application.

## Data that remains in the browser

- project names and document IDs;
- participant and role labels;
- answers, notes, contribution provenance, and resolutions;
- imported premise documents and Override patches; and
- Base, Unified, and AI Context output generated by the user.

This information is stored only in browser storage on the current device and origin. It is not placed in URLs, query strings, fragments, referrers, page titles, cookies, analytics, telemetry, or remote error reports.

## Public application requests

The host serves public HTML, CSS, JavaScript, schemas, template manifests, question wording, rules, and mappings. These application files contain no user responses. After those files load, the application does not need a network connection for project work.

## User-controlled transfer

Import parsing, validation, merging, and export generation run locally. Selecting a file does not upload it. Downloading or copying an export does not publish it. A later decision to share an export, send it to an AI, or commit it to GitHub occurs outside Premise Builder.

Clearing site data, switching browser profiles, or changing origins can remove or make local work unavailable. Export is the portable backup mechanism.
